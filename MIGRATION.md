# ClawDocu Comment Storage

## File Location

Comments are stored in: `.clawdocu-comments/comments.json`

## Structure

```json
{
  "files": [
    {
      "path": "TEST-GUIDE.md",
      "comments": [
        {
          "id": "1778517629104",
          "lineNumber": 130,
          "selectedText": "...",
          "text": "...",
          "createdAt": "2026-05-12T..."
        }
      ]
    }
  ]
}
```
