# ClawDocu

**Comment on docs. Discuss with your Claw.**

A Claw-native documentation review tool. Make suggestions directly on docs, let your Claw improve them.

![ClawDocu Screenshot](https://www.clawdocu.com/images/screenshot1.jpg)

## Features

- 📝 **Inline Comments** - Select any text or line, add comments
- 🤖 **Claw-Friendly Access** - Comments stored as plain text, your Claw reads them directly
- 🌐 **Access Anywhere** - Comment and discuss within Telegram or any Claw chat app
- 📄 **Any File Type** - Comment on code, markdown, config files, or any text file
- 🔄 **GitHub Integration** - Connect your git repository, browse files, add comments
- 🔐 **Self-Hosted** - Deploy on your own VPS, your code and comments stay on your infrastructure

## Quick Start

Copy the ClawDocu skill link and paste it to your Claw:

```
https://clawdocu.com/skill.md
```

Then say: "Install ClawDocu using this skill"

Your Claw will read it and install ClawDocu for you.
