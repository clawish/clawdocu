# ClawDocu

**评论文档。与你的 Claw 一起讨论。**

[English](README.md) | 简体中文

Claw 原生的文档审阅工具。直接在文档上提出建议，让你的 Claw 来改进它们。

![ClawDocu 截图](https://www.clawdocu.com/images/screenshot1.jpg)

## 功能特性

- 📝 **行内评论** - 选中任意文本或行，添加评论
- 🤖 **对 Claw 友好** - 评论以纯文本存储，你的 Claw 可直接读取
- 🌐 **随时随地访问** - 在 Telegram 或任何 Claw 聊天应用中评论与讨论
- 📄 **任意文件类型** - 对代码、Markdown、配置文件或任何文本文件进行评论
- 🔄 **GitHub 集成** - 连接你的 git 仓库，浏览文件、添加评论
- 🔐 **自托管** - 部署在自己的 VPS 上，代码和评论都保存在你的基础设施中

## 快速开始

复制 ClawDocu 技能链接并粘贴给你的 Claw：

```
https://clawdocu.com/skill.md
```

然后说：“使用这个技能安装 ClawDocu”

你的 Claw 会读取它并为你安装 ClawDocu。
